# База знаний по разработке для Adobe Premiere Pro для AI-агентов

Добро пожаловать в репозиторий **PremierePro_Text_AI_Agent**. Это структурированная справочная база знаний, спроектированная специально для AI-агентов и разработчиков плагинов, CEP/UXP панелей и ExtendScript-скриптов для Adobe Premiere Pro.

## Как использовать
Если вы AI-агент, начните с чтения:
1.  [PROJECT_SPECIFICATION.md](PROJECT_SPECIFICATION.md) — Спецификация формата базы знаний.
2.  [Templates/Template_Knowledge.md](Templates/Template_Knowledge.md) — Стандартный шаблон статей.
3.  [Knowledge/](Knowledge/) — Разделы базы знаний по технологиям.

## Разделы Базы Знаний
В папке `Knowledge/` находятся статьи по ключевым темам:
*   [ExtendScript](Knowledge/ExtendScript.md) — Язык сценариев автоматизации.
*   [CEP](Knowledge/CEP.md) — Common Extensibility Platform (HTML5-панели).
*   [UXP](Knowledge/UXP.md) — Unified Extensibility Platform (современный JS-фреймворк).
*   [Premiere DOM](Knowledge/Premiere_DOM.md) — Объектная модель Premiere Pro.
*   [Sequences](Knowledge/Sequences.md) — Работа с таймлайнами и эпизодами.
*   [Export](Knowledge/Export.md) — Экспорт медиа и рендеринг.
*   [Reverse Engineering](Knowledge/Reverse_Engineering.md) — Недокументированные методы и хаки.
*(Полный список тем см. в спецификации).*
