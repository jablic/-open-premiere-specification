# Техническая спецификация проекта: PremierePro_Text_AI_Agent

## 1. Введение и Цель
**PremierePro_Text_AI_Agent** — это модульная база знаний по разработке расширений, плагинов и скриптов для Adobe Premiere Pro. База знаний разработана специально для использования AI-агентами (LLM) и разработчиками, чтобы минимизировать галлюцинации и предоставить 100% достоверный источник информации.

## 2. Структура проекта
Структура проекта является окончательной и не подлежит изменению без крайней необходимости:
*   `README.md` — Вводное руководство по проекту.
*   `PROJECT_SPECIFICATION.md` — Настоящий документ спецификации.
*   `Knowledge/` — Папка со статьями базы знаний по направлениям.
*   `Templates/` — Шаблоны для создания новых документов.
*   `Examples/` — Рабочие примеры кода и сценарии.
*   `Research/` — Исследования, заметки, дампы API и результаты reverse engineering.
*   `Archive/` — Архив устаревших данных.

## 3. Требования к контенту в Knowledge/
Каждый файл базы знаний должен создаваться по шаблону `Templates/Template_Knowledge.md` и содержать:
1.  **Суть и Назначение**
2.  **Архитектура и Взаимодействие**
3.  **Справочник API** (с указанием типов)
4.  **Ограничения и Известные Проблемы**
5.  **Reverse Engineering и Недокументированные Возможности**
6.  **Распространенные Ошибки и Антипаттерны**
7.  **Production-Ready Примеры Кода**
8.  **Практические Рекомендации**
9.  **Источники**

## 4. AI-ориентированные правила форматирования
*   **Использовать теги:** Указывать теги в начале каждого документа для RAG-индексации.
*   **Точное указание контекста:** Четко разграничивать ExtendScript (JSX), CEP (HTML/JS) и UXP (JS/CSS).
*   **Только рабочий код:** Никакого псевдокода или устаревших API без пометки `Deprecated`.

## 5. Процесс наполнения
Каждая тема проходит через следующие этапы:
1.  Сбор официальной документации Adobe.
2.  Сбор информации из комьюнити (форумы, блоги, Stack Overflow, GitHub).
3.  Выгрузка реального API через дамперы рефлексии (ExtendScript/UXP).
4.  Фильтрация, удаление дубликатов и компоновка в Markdown.
