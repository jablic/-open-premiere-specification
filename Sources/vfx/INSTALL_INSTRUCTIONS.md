# DaVinci Resolve - Export by Markers Script

Автоматический пакетный экспорт видео по маркерам в DaVinci Resolve.

## Файлы установщика

### 1. **davinci-export-installer.dmg** (рекомендуется)
Полный пакет для распространения — содержит всё необходимое.

**Установка:**
```bash
# Просто двойной клик на DMG файл
# Откроется окно с PKG установщиком и инструкциями
# Двойной клик на DaVinci-Export-by-Markers.pkg
# Следуй инструкциям
```

### 2. **DaVinci-Export-by-Markers.pkg** (отдельный файл)
Стандартный macOS установщик PKG.

**Установка:**
```bash
# Двойной клик и следуй инструкциям
# или через Terminal:
open DaVinci-Export-by-Markers.pkg
```

### 3. **install.sh** (альтернатива)
Простой shell скрипт для установки.

**Установка:**
```bash
chmod +x install.sh
sudo ./install.sh
```

## Что устанавливается

```
/Library/Application Support/Blackmagic Design/
  └── DaVinci Resolve/
      └── Fusion/
          └── Scripts/
              └── Utility/
                  └── export_by_markers.lua
```

## Использование скрипта

1. Открой DaVinci Resolve
2. Перейди в **Fairlight → Workspace → Scripts → Utility**
3. Выбери **export_by_markers**
4. В таймлайне должны быть маркеры с названиями
5. Скрипт запустится и создаст очередь экспорта

**Вывод** смотри в **Fairlight → Workspace → Console (F6)**

## Результат

- Видеофайлы экспортируются в `~/Desktop/Export/`
- Имена файлов совпадают с названиями маркеров
- Параметры экспорта — текущие настройки проекта

## Что делает скрипт

```lua
Для каждого маркера с названием:
  1. Установить начало экспорта (MarkIn)
  2. Установить конец экспорта (MarkOut)
  3. Добавить в очередь рендера
  4. Запустить экспорт всех видео
```

## Требования

- **macOS:** 10.13 или выше
- **DaVinci Resolve:** 15.0 или выше
- **Свободное место:** для экспорта видео

## Возможные проблемы

| Проблема | Решение |
|----------|---------|
| "No Scripts" в меню | Перезагрузи DaVinci полностью |
| Ошибка прав доступа | Используй `sudo` при установке |
| Скрипт не запускается | Убедись, что есть маркеры в таймлайне |

## Обновление скрипта

Если выпустится новая версия:
1. Удали старый: `rm "/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/export_by_markers.lua"`
2. Установи новый установщик
3. Перезагрузи DaVinci
